# Changelog

## 1.1.2

- Removed source-migration section markers and interactive-shell dependencies from the production engine.
- Standardized worker diagnostics on plain process logs.
- Documented that `build_instructions.html` is generated by the repository reporting service from validated run artifacts.
- Added repository-independence and HTML-generation provenance checks.

## 1.1.1

- Replaced R&D-style regression dumps with compact reviewed source-repository fixtures.
- Renamed the unlimited airplane fixture to `airplane_reference_unlimited`.
- Added an explicit `airplane_standard_kit` infeasibility fixture.
- Added structured `INFEASIBLE_INVENTORY` handling for finite-kit build failures.
- Removed workbook implementation terminology from user-facing build visualizations.
- Added visible inventory-basis labeling to interactive build instructions.
- Excluded regression fixtures and generated test runs from production distributions.

## 1.1.0

- Added deterministic validated execution mode.
- Moved LLM use to contract authoring; validated builds cannot call an LLM.
- Added provisional exploratory mode and final-claim gating.
- Added immutable `validated-1` contract revisions for packaged models.
- Added execution-policy tests and run-manifest provenance.
- Retained canonical interactive `build_instructions.html` output.

## 1.0.1

- Added canonical `build_instructions.html` output for all file-writing planner runs.
- Made validated row/column builds write the interactive 3D player to both
  `build_instructions.html` and the legacy
  `visualizations/proper_complete_build_steps.html` path.
- Added `build_instructions_html` to run summaries while preserving the legacy
  `true_build_player_html` field.
- Added tests and documentation for the HTML instruction artifact.

## 1.0.0

- Finalized a model-agnostic, contract-driven runtime.
- Consolidated immutable model geometry in the content-addressed `model_store/`.
- Consolidated task contexts and confirmation artifacts in the versioned `model_registry/`.
- Isolated every execution under `runs/<run-id>/`.
- Moved reviewed regression baselines from runtime outputs to `tests/regression/`.
- Removed historical R&D-version identifiers from code, contracts, documentation, test fixtures, and generated artifact names.
- Retained the original `block_definitions.xlsx` as the sole block catalog.
- Retained separate finite and unlimited inventory profiles.
- Preserved the reviewed bird and airplane builds through the generic runtime.
- Ensured player instructions and module status are displayed outside the 3D canvas.
